# PromptDocentes

PromptDocentes es un generador gratuito de superprompts educativos creado por **Teacher MikeSL**. Ayuda al profesorado a describir con claridad el recurso que necesita, contextualizarlo para su grupo y conectarlo con las referencias curriculares disponibles de Andalucía.

La aplicación funciona completamente en el navegador: no exige registro, no envía formularios y no almacena lo que escribe el usuario. El resultado es un prompt que el docente copia y utiliza en la IA de su elección.

Entre los recursos disponibles se encuentra **Proyecto de curso completo**, un recorrido por fases para diseñar el mapa anual, validar una secuencia piloto y producir después las unidades, materiales, evaluación e inventario final sin confundirlo con una única programación anual. El prompt solicita también una vista docente atractiva con índice inicial, carpetas numeradas, iconos acompañados de texto y documentos accesibles con identidad propia.

## Estado curricular

- Infantil, Primaria, ESO y Bachillerato: colecciones curriculares estructuradas incorporadas.
- Formación Profesional: catálogo guiado de títulos y módulos; desarrollo curricular completo en fase piloto para DAW, módulo 0612.
- Otras enseñanzas: recorrido guiado con aportación o verificación de la referencia específica por parte del docente.

La publicación oficial firmada prevalece siempre. PromptDocentes no sustituye el criterio profesional ni la revisión docente.

## Privacidad

No introduzcas nombres, contactos, diagnósticos vinculados a personas ni otros datos identificativos del alumnado. Aunque PromptDocentes no envía ni guarda el formulario, el prompt se copiará después en una herramienta de IA externa con sus propias condiciones.

## Publicación

GitHub Pages publica automáticamente el contenido de `dist/` mediante el flujo definido en `.github/workflows/pages.yml`.
